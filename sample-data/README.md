## Sample 1 — High novelty, reasonable budget
**Title:** AI-Based Predictive Maintenance for Longwall Mining Equipment
**Proposer:** IIT Kharagpur · **Budget:** 65 lakhs · **Duration:** 18 months

This project proposes a predictive maintenance system for longwall mining
equipment using vibration sensors, acoustic emission monitoring, and a deep
learning model trained to detect early signs of mechanical failure in shearer
drums and armored face conveyors. Unlike existing reactive maintenance
practices, this system will provide 48-72 hour advance failure warnings,
reducing unplanned downtime and improving worker safety.

## Sample 2 — Near-duplicate (tests novelty detection)
**Title:** Machine Learning Model for Mine Slope Failure Prediction
**Proposer:** NIT Rourkela · **Budget:** 40 lakhs · **Duration:** 12 months

This project aims to develop a machine learning-based system for predicting
slope stability and failure risk in opencast coal mines, using historical
geotechnical data, rainfall patterns, and slope geometry to flag high-risk
zones before failure occurs.

---

## Sample 3 — Over-budgeted (tests financial flag)
**Title:** Dust Suppression Drone Swarm for Opencast Mines
**Proposer:** BIT Mesra · **Budget:** 350 lakhs · **Duration:** 10 months

A swarm of autonomous drones with fine water-mist sprayers to suppress
airborne coal dust in opencast mining areas, coordinated by a central control
system that responds to real-time dust sensor readings across the mine site.

---

## Sample 4 — Under-budgeted (tests financial flag)
**Title:** National-Scale Coal Reserve Estimation Platform Using Satellite AI
**Proposer:** ISM Dhanbad · **Budget:** 15 lakhs · **Duration:** 36 months

A nationwide platform using satellite imagery and deep learning to estimate
coal reserves across all major Indian coalfields, integrating multispectral
imaging, geological survey data, and historical extraction records into a
unified reserve-estimation dashboard.
